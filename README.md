# Pozo Limpio

Survival horror cenital: defiende el pozo de agua limpia con la manguera. Diseño y reglas en [`CLAUDE.md`](CLAUDE.md).

```bash
npm install
npm run dev     # juego en http://localhost:5173
npm test        # pruebas de la lógica (node --test)
npm run build   # sitio estático en dist/
```
